# Neural Complete

以《图灵完备》式“构造 → 模拟 → 测试 → 调试 → 抽象”为核心机制的神经网络教学游戏实验。

## 当前 Demo：P-01 人工神经元

这一版已经推翻旧的“按 Forward / Loss / Backward 按钮看演示”方案。

玩家面对的是一个真正的构造谜题：

- 画布上只有固定的两个输入端口和一个输出端口；
- 从数量受限的原始元件仓中拖入 `CONST / MULTIPLY / ADD / STEP`；
- 自由摆放元件并直接进行端口接线；
- 调整常数，构造自己的计算图；
- 用测试台逐例传播真实数值；
- 观察每个元件、端口和导线上的即时信号；
- 根据失败反例调试；
- 通过公开测试后再接受额外校验；
- 完成后把自己的底层构造封装为新的 `NEURON_01` 抽象积木。

核心思想不是“教用户点按钮训练”，而是让玩家先亲手发现：

```text
多个输入
→ 不同权重缩放
→ 汇总
→ 偏置
→ 阈值
→ 决策
```

这套结构最终可以被压缩成一个“神经元”。

## 运行

```bash
cd /home/ubuntu/workspace/neural-complete
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4173`。

## 操作

- 从底部元件仓拖拽元件到画布；
- 点击一个输出端口，再点击目标输入端口完成接线；
- 拖拽元件标题移动位置；
- 点击 `CONST` 后在右侧检查器修改数值；
- `Delete` 删除选中的元件或导线；
- `Esc` 取消接线；
- `Ctrl+Z` 撤销；
- 测试台可单步运行或运行全部公开测试。

## 关卡验收

第一关成功条件：

1. 6 个公开测试全部通过；
2. 4 个额外校验全部通过；
3. 最终可把当前构造封装为 `NEURON_01`；
4. 清空底层电路后，`NEURON_01` 可以像普通元件一样重新拖入画布，并用 `x1 / x2 / out` 三个端口再次完成同一测试契约。

测试计算全部在浏览器本地实时执行，不使用预制动画。

## 自动验证

仓库包含两套真实浏览器测试：

- `e2e_check.py`：从空白画布经历失败、完整搭建、公开测试、隐藏校验、封装、宏组件复用和刷新持久化；
- `edge_check.py`：检查回路诊断、输入重接、Esc 取消接线、删除/撤销持久化和不同桌面尺寸下的画布边界。

测试需要 Python Playwright 与 Chromium。
